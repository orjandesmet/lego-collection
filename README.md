# Orjan's Lego Collection

A site to catalog all lego sets and minifigs I own or wish to own.
Built with AstroJS, styling done with Tailwind.
Deployed on netlify (https://lego.orjan.be).
Icons from [Modern UI Icons](https://www.svgrepo.com/collection/modern-ui-icons/) collection.

A GitHub action exists to add a set/minifig and start a new deployment.
